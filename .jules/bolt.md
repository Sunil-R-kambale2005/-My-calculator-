## 2025-08-04 - DOM Event Delegation and Selector Caching
**Learning:** Inline event handlers (like `onclick="..."` on dozens of buttons) and repeated queries of elements in high-frequency user actions cause unnecessary DOM operations, waste CPU cycles, and bloat the HTML size. By using single-listener Event Delegation (`event.target.closest`) on a parent container and caching the input display selector once, we eliminate repeated layout/style recalculation from selector resolution and minimize memory allocation for event handlers.
**Action:** Always prefer Event Delegation and pre-caching selectors when handling interactions for lists, tables, grids, or button groups instead of attaching individual inline event listeners or calling `document.querySelector` on every event callback.
