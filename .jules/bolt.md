## 2024-08-12 - DOM Querying and Inline Event Handlers Bottleneck in Static HTML Calculator
**Learning:** Having inline event handlers (e.g., `onclick="..."`) on 17 distinct buttons causes code duplication, increased HTML size, and forces browser layout engines to parse/re-compile JavaScript handlers repeatedly. Furthermore, querying the DOM via `document.querySelector('#display')` on every single click introduces unnecessary overhead that degrades performance and responsiveness during fast typing or sequential button clicks.
**Action:** Consolidate event handlers into a single click event listener on `.btn-container` using event delegation, and cache the DOM reference to `#display` at initialization. This significantly improves event binding efficiency, memory usage, and runtime execution speed.
